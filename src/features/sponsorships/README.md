# Sponsorships

Approved organizations can post an in-kind need with a unit and target quantity. A signed-in neighbor may make one pledge per need. A Firestore transaction updates the pledge total, closes the need when full, and notifies the organization owner. Okoa Food records commitments only; it does not collect payments or arrange delivery.

Needs may include an optional direct http or https image URL from any host. Four presentation needs are connected to demo organization accounts and accept pledges normally. Listings and details show pledge progress.

The public needs page explains the account → organization application → administrator approval → post a need flow, with an entry action for every account state. Signup/login preserves the intended application destination. Approved applicants receive direct links to post a need and request donations.
