# Home

Landing page and workflow explanation. The impact strip uses Firestore count aggregations for available donations, received donations, and approved organizations. Counts are refreshed when the home page opens; no stored counter or stats pipeline is needed.

The hero uses an [Unsplash photo of volunteers sorting donated food](https://unsplash.com/photos/3k3l2brxmwQ). Sample donations and partner profiles are excluded from impact totals.
